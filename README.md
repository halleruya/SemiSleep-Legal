# SemiSleep Legal Pages

This directory is ready to publish with GitHub Pages.

Recommended GitHub Pages setting:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

Expected public URLs after GitHub Pages is enabled:

- Site: `https://halleruya.github.io/SemiSleep-Legal/`
- Privacy Policy URL: `https://halleruya.github.io/SemiSleep-Legal/privacy-policy/`
- Terms of Use URL: `https://halleruya.github.io/SemiSleep-Legal/terms/`
- Legal Disclosure URL: `https://halleruya.github.io/SemiSleep-Legal/legal-disclosure/`
- Support URL: `https://halleruya.github.io/SemiSleep-Legal/support/`

App Store Connect fields:

- Privacy Policy URL: use `/privacy-policy/`
- Support URL: use `/support/`
- App description or EULA/terms field: include `/terms/` if needed

Notes before App Store submission:

- The current support contact uses GitHub Issues because no public support email was present in the repository.
- If you want a lower-friction support route, add a public support email or contact form to `support/index.html`, `privacy-policy/index.html`, and `legal-disclosure/index.html`.
- The App Store privacy label should match the app behavior. Based on the current source, the likely answer is that the developer does not collect data, with StoreKit purchases handled by Apple.
